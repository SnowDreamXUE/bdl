# BDL v0.9.0

## 内容库与解析

- 新增「稍后再看」：使用与收藏、订阅一致的卡片列表，点击进入视频、分 P 或所属合集详情。清单分页浏览，不提前逐条解析下载地址。
- 合集支持分组树，保留分区层级、分组勾选与跨页选择；视频行沿用列表布局。
- PC 和 Android 支持点击卡片选择、再次点击取消；播放与其他按钮独立响应。
- 新增可选剪贴板识别，在设置中开启后于返回应用时读取，默认关闭。
- 修复稍后再看补全后出现“选中的分 P 未加载”的下载错误，以及多分 P 详情的计数、分页和选择。
- 收藏、订阅进入时自动刷新，刷新统一显示骨架屏；精简重复标题和操作提示。

## NFO 与文件命名

- 下载预设支持 NFO 媒体资料配置，提供标题、简介、标签、日期、时长、封面、UP 主、排序和作品集等字段。
- 增加常用展示方案、自定义模板与变量插入，支持按 UP 主或多 P 归组。
- 文件命名支持清晰度名称、日期格式等变量；NFO 与封面输出保持关联。
- 使用说明：[NFO 媒体资料与模板](https://github.com/Yuelioi/bdl/blob/v0.9.0/docs/NFO.md)。

## 更新与体验

- 更新来源支持 GitHub、GitHub 加速和夸克手动下载；提供夸克跳转入口。桌面自动安装继续验证更新签名，Android 通过浏览器下载安装包。
- FFmpeg 设置增加下载入口和配置说明。
- 详情与解析页长标题缩小并省略，悬停显示完整标题，避免挤压下载按钮；同步调整手机和平板布局。
- 桌面端记住窗口位置、大小与最大化状态，首次启动默认居中。

## 安装说明

- Windows、macOS、Linux 请下载对应平台安装包；CLI 包单独提供。
- macOS 包采用 ad-hoc 签名，未经 Apple 公证。首次启动请按 README 的“右键打开”或“隐私与安全性 → 仍要打开”指引操作。
- Android ARM64 APK 为开发预览，已内置 FFmpeg；请使用本 Release 中项目签名的安装包。
