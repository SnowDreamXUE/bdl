# BDL v0.9.1

## 错误详情与反馈

- 首次解析、批量解析、分页加载、内容库和下载设置失败时保留错误码与原始原因，提供错误详情、复制诊断信息和问题反馈入口。
- 诊断信息包含失败时间、来源及应用环境，并对 Cookie、令牌等敏感内容进行脱敏；复制失败时可展开详情手动复制。
- 在「设置 → 网络与维护 → 清理与诊断」查看、复制或清空本次运行最近 20 条操作错误，切换页面后仍可查阅；退出应用后清空。
- 诊断导出包含尚未创建下载任务的解析错误；补全后端通用失败日志，保留旧格式错误对象中的具体原因。

## 解析与后台下载修复

- 修复限流原因仅存在于错误详情时，后台解析下载仍继续请求下一条视频的问题。
- 后台整体失败及单项失败保留诊断信息，分页重试成功后清除过期错误。
- 下载大小估算失败不再静默丢弃原因，可查看诊断并继续尝试下载。
- 补全目录选择和停止解析失败的诊断入口，共享界面同步覆盖桌面与 Android。

## 安装说明

- Windows、macOS、Linux 请下载对应平台安装包；CLI 包单独提供。
- macOS 包采用 ad-hoc 签名，未经 Apple 公证。首次启动请按 README 的“右键打开”或“隐私与安全性 → 仍要打开”指引操作。
- Android ARM64 APK 为开发预览，已内置 FFmpeg；请使用本 Release 中项目签名的安装包。
