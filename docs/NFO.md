# NFO 媒体资料与模板

NFO 是放在视频旁边的 XML 资料卡，供 Kodi、Jellyfin 等媒体库读取。它可以决定媒体库显示的标题、简介、分类等，**不会修改视频文件名或视频画面**。

在 **设置 → 下载预设 → 编辑 → 内容** 中勾选“生成 NFO”，然后到“转换 → NFO 媒体信息”。每个任务保留创建时的配置，后续编辑预设不会改动已有任务。

## 直接使用

默认方案会写入可获取的任务标题、视频简介、UP 主、发布日期、时长、B 站分区和唯一标识。还可以独立保存封面、填写固定标签，并选择是否将 UP 主加入人物列表，便于筛选。UP 主人物的角色是“UP 主”，不表示该用户是演员或导演。

“套用展示方案”提供：

| 方案 | 效果 |
| --- | --- |
| 标准资料卡 | 使用任务标题和视频简介，进阶字段留空 |
| 按 UP 主归类 | UP 主作为作品集；按 UP 主、发布日期、视频名、分 P 序号排序；附加 UP 主和分区标签 |
| 多 P 视频归组 | 标题显示视频总名、P 序号和分 P 名；同一视频归为一个作品集，按补零的 P 序号排序 |

套用会替换标题、简介和全部进阶字段，保留字段开关和固定标签。作品集是独立视频的分组，不是电视剧的季/集。

## 字段如何选择

| 字段 | 用途与来源 |
| --- | --- |
| 标题、完整简介 | 默认读取视频信息，也可用模板组织文字 |
| 日期、时长、分区 | 可分别开关；缺少数据时省略，不凭经验推测 |
| 原始标题 | 保留原名称，例如 `{video_title}` |
| 排序标题 | 只改变媒体库排序，不改变显示名称，例如 `{publish_date} - {part_index:03}` |
| 一句话介绍、短简介 | 简略资料；显示位置由媒体库及其主题决定 |
| 固定标签 | 输入 `教程, 收藏`；中英文逗号或换行分隔；按普通文字处理 |
| 动态标签 | 输入 `{uploader}, {quality_label}`，生成实际 UP 名和清晰度；与固定标签合并去重 |
| 附加分类 | 逗号分隔，可与 B 站分区合并；关闭自动分区后可完全自定义 |
| 作品集名称、简介 | 将独立视频归组；只填写简介而没有名称时不输出作品集 |
| 导演、编剧、制作机构、国家或地区 | 可直接填写或使用模板，但只应填写已知事实；多项用逗号分隔 |
| 来源标识 | 使用 B 站标识，多 P 的 BV+CID 不同，避免被视为同一条资料 |
| 封面 | 需同时选择下载封面和独立保存；输出同名 `-poster` 图片，保留图片扩展名 |

同一个预设会应用到所有使用它的任务。不要在通用预设中填入只属于某一个视频的导演、机构或地区。平台视频标签暂未自动请求，固定与动态标签可用于整理。

## 变量与文件命名的关系

用法相同：输入框旁的 **＋** 打开变量菜单，点击中文说明对应的变量，插入到光标位置；选中了文字则替换选中文字。标题和简介均支持，进阶字段也支持。可以输入普通文字，不必全部使用变量。示例区使用虚拟数据，实际输出取任务快照中的真实数据。

| 变量 | 含义 |
| --- | --- |
| `{title}` | 任务标题 |
| `{video_title}` / `{part_title}` | 视频总标题 / 分 P 标题 |
| `{part_index}` / `{index}` | 分 P 序号 / 来源列表中的视频序号，均从 1 开始 |
| `{source_title}` | 本次解析的来源标题，例如收藏夹名称；单视频解析时为视频标题 |
| `{description}` / `{genre}` | 视频简介 / 平台分区 |
| `{uploader}` / `{owner_mid}` | UP 主名称 / UID |
| `{publish_date}` / `{date}` | 发布日期 / 任务创建日期 |
| `{bvid}` / `{aid}` / `{cid}` | BV / AV 数字编号 / 分 P 内容编号 |
| `{source_url}` | 原视频、番剧或课程链接；普通多 P 链接包含 P 参数 |
| `{quality_label}` / `{quality}` | 所选视频清晰度名称（如 1080P）/ 原始编号（如 80） |
| `{codec}` / `{duration_seconds}` | 所选视频编码 / 时长秒数 |

NFO 支持 `{part_index:02}`、`:03`、`:04`（也适用于 `index`）补齐序号。例如 `2` 转成 `002`，便于文本排序。

日期支持 `%Y-%m-%d`、`%Y.%m.%d`、`%Y%m%d`，例如 `{publish_date:%Y.%m.%d}` 输出 `2026.10.18`。这只影响模板里的文字；NFO 的正式发布日期保持 `YYYY-MM-DD`，供媒体库识别。

NFO 和文件命名的变量集合不完全相同，应使用各自菜单。文件命名同样支持 `{quality_label}` 和上述日期格式；原 `{quality}` 保留数字编号，已有命名不会被悄悄更改。

## 媒体库兼容范围

- 输出 UTF-8、同视频名的 `.nfo`，使用独立视频 `movie` 格式；实际导入请使用媒体库的电影/独立视频类型。
- 标题、简介等文本安全转义，未知变量会阻止保存；新增配置对旧预设和旧任务有默认值。
- 普通视频的简介和分区来自解析结果；番剧、课程等未提供的字段不会自动补造。
- 不把平台点赞/播放量换算成评分，不生成观看次数或观看进度，不把画质档位当作真实像素尺寸。媒体库可自行读取技术信息和管理观看状态。
- 不自动转换成 `tvshow` / `episodedetails`，不推测季集编号。该模式还需要正确的目录布局、剧集来源和季集映射。
- 不提供任意 XML 标签编辑；播放器通常忽略不认识的字段。不同媒体库版本对作品集、短简介和人物等的展示可能不同。
- 已验证配置保存、任务快照、XML 解析和界面交互；尚未完成实际 Kodi/Jellyfin/Emby 媒体库导入验收。
